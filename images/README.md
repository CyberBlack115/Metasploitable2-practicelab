# Screenshots

Put screenshots for this repo here. Each write-up has a box that says *Screenshot goes here* and tells you the file name to use.

**How to add one**
1. On GitHub, open this `images` folder → **Add file** → **Upload files**.
2. Upload the screenshot using the exact name from the box.
3. Open the write-up, edit it, delete the placeholder box, and uncomment the image line below it.

**Before uploading:** check that no real passwords, tokens or personal details are visible.
